# ListarArchivosReferenciaEnBinD

Este programa carga un archivo .bind y muestra por pantalla los archivos de referencia que tiene referenciados.

## Requisitos

- SDK de .NET 10.
- Digi3D.AI para .NET 10 instalado en el equipo, para ejecutar el programa.

El proyecto referencia el paquete `Digi21.DigiNG.IO.BinDouble` 26.0.0.

## Uso

```
ListarArchivosReferenciaEnBinD.exe [tabla de códigos] [archivo bind]
```

Ejemplo: `ListarArchivosReferenciaEnBinD.exe digiBCA.Tab.xml 29091711.bind`
