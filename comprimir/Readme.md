# Comprimir

Este programa de consola comprime el archivo .BIND pasado por parámetros: elimina las entidades que tienen la marca de borrado.

## Requisitos

- SDK de .NET 10.
- Digi3D.AI para .NET 10 instalado en el equipo, para ejecutar el programa.

El proyecto referencia el paquete `Digi21.DigiNG.IO.BinDouble` 26.0.0.

## Uso
```bash
comprimir.exe [ruta al archivo .bind a comprimir]
```

## Ejemplo
```bash
comprimir archivo.bind
```
